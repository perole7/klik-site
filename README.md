# Klik — Website Oficial

Landing page e site profissional da **Klik**, desenvolvido com foco em alta conversão, autoridade e velocidade.

## Tecnologias & Estrutura
- **HTML5 Semântico**: Estrutura acessível com metadados e Schema.org.
- **CSS3 Moderno**: Folha de estilos proprietária sem frameworks genéricos, responsiva e performática.
- **Tipografia**: Outfit & Plus Jakarta Sans.
- **JavaScript Puro**: Sem bibliotecas pesadas, integração direta com WhatsApp.

## Como Visualizar Localmente
Basta abrir o arquivo `index.html` em qualquer navegador ou rodar um servidor local HTTP:
```bash
python -m http.server 8080
```
Acesse: `http://localhost:8080`
